Capítulo 05 de 08

Reconstrução do caminho

Saber que a viagem custa 6 não diz por onde passar. A segunda matriz guarda, para cada par, apenas a próxima parada, e isso é suficiente para montar o caminho inteiro.

Animação interativaFunciona sem internet

Guarde só o primeiro passo

Imagine placas de estrada. Nenhuma placa desenha o trajeto inteiro; ela só diz para onde virar agora. Chegando na próxima cidade, outra placa diz o passo seguinte. Seguindo placa por placa você chega ao destino.

next_vertex[i][j] é essa placa: o primeiro vértice a visitar depois de i, no caminho escolhido até j. Se o caminho de A até D é A → B → C → D, então next_vertex[A][D] vale B, mesmo com o destino três arestas adiante.

Quando a distância melhora, a placa também muda

A linha que faz isso no projeto é curta e é a parte que mais gera dúvida:

if candidate < dist[i][j]:
    dist[i][j] = candidate
    next_vertex[i][j] = next_vertex[i][k]

A placa nova não aponta para k. Ela copia a placa que já existia para chegar em k. Motivo: o caminho novo começa fazendo o trecho i → k, então o primeiro passo dele é o primeiro passo desse trecho. Na etapa k = C, o par A → D melhora usando A → C → D, mas A → C já significava A → B → C. Por isso a placa recebe B, não C.

Acompanhe as duas matrizes sendo preenchidas juntas. A de baixo é a das placas.

Use melhora estrita

Mantenha < e não <=. Em empate, preservar a placa antiga evita trocar um caminho válido por outro de mesmo custo e, em certos empates envolvendo a diagonal, evita criar uma placa que aponta para a própria origem e deixa a reconstrução presa em um laço.

Siga as placas até o destino

Escolha origem e destino e avance um vértice por vez. A célula em destaque é a consulta que está sendo feita. Repare que a coluna consultada é sempre a do destino; só a linha muda conforme você anda.

Esta animação precisa de JavaScript. Com ele desligado, use o texto e as tabelas desta página, que contêm os mesmos números.
def reconstruct_path(source, target, next_vertex):
    if next_vertex[source][target] is None:
        return []
    path = [source]
    current = source
    while current != target:
        current = next_vertex[current][target]
        path.append(current)
    return path

Se não há caminho, a função devolve a lista vazia []. Se origem e destino são iguais, o laço não executa nenhuma vez e a resposta é a lista com um único vértice.

Confira o entendimento

Você está em B e quer chegar a D. Consulta a célula B, C ou a célula B, D?

B, D. O destino continua sendo D; o que mudou foi a sua posição atual. Essa célula guarda C, que é a próxima parada. Depois de chegar em C, a consulta é C, D.

Outra fonte usa uma matriz de predecessores. É a mesma coisa?

É a ideia espelhada. Predecessor guarda quem vem imediatamente antes, e o caminho é montado de trás para frente, do destino até a origem, invertendo a lista no fim. Este material usa o próximo vértice porque a reconstrução sai na ordem em que se anda.
