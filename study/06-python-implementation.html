O arquivo inteiro

src/floyd_warshall/application/floyd_warshall_solver.py
class FloydWarshallSolver(ShortestPathSolver):
    """Implementação própria do algoritmo Floyd-Warshall."""

    def solve(self, graph: Graph) -> ShortestPathResult:
        vertices = graph.vertices()
        n = len(vertices)
        index = {vertex: i for i, vertex in enumerate(vertices)}

        dist = [[inf] * n for _ in range(n)]
        next_vertex: list[list[int | None]] = [[None] * n for _ in range(n)]

        for i in range(n):
            dist[i][i] = 0.0

        for origin, destination, weight in graph.edges():
            i = index[origin]
            j = index[destination]
            if weight < dist[i][j]:
                dist[i][j] = float(weight)
                next_vertex[i][j] = j

        initial_distances = [row[:] for row in dist]

        for k in range(n):
            for i in range(n):
                if dist[i][k] == inf:
                    continue
                for j in range(n):
                    if dist[k][j] == inf:
                        continue
                    candidate = dist[i][k] + dist[k][j]
                    if candidate < dist[i][j]:
                        dist[i][j] = candidate
                        next_vertex[i][j] = next_vertex[i][k]

        for i in range(n):
            if dist[i][i] < 0:
                raise NegativeCycleError(
                    f"Ciclo de peso negativo detectado envolvendo '{vertices[i]}'."
                )

        return ShortestPathResult(
            vertices=vertices,
            initial_distances=initial_distances,
            distances=dist,
            next_vertex=next_vertex,
        )

Quatro decisões que valem explicar na apresentação

O dicionário index

A matriz é indexada por números, mas os vértices têm nomes como "A" ou "Porto Alegre". index traduz nome para posição uma única vez, e vertices traduz de volta na hora de mostrar o resultado.

Os dois continue

Se dist[i][k] é infinito, nenhum j vai salvar essa linha: a soma daria infinito de qualquer jeito. O primeiro continue pula o laço de j inteiro. Isso não muda o resultado nem a complexidade no pior caso, mas evita trabalho inútil em grafos esparsos. Na animação, esses passos aparecem com a mensagem "nem precisa somar".

A cópia initial_distances

[row[:] for row in dist] guarda uma fotografia da matriz antes do algoritmo começar. A interface usa essa cópia para mostrar o antes e o depois. Sem o [:], as duas listas apontariam para as mesmas linhas e a fotografia mudaria junto com o original.

A verificação final da diagonal

Depois dos três laços, o código percorre a diagonal. Se algum dist[i][i] ficou negativo, existe um ciclo de peso negativo passando por i, e o resultado perde sentido. O projeto levanta NegativeCycleError em vez de devolver números enganosos. O capítulo 07 mostra esse caso animado.
